# 基于RAG的Python小学智能教育问答系统

## 项目简介

本项目是一个基于检索增强生成(Retrieval-Augmented Generation, RAG)技术的Python小学智能教育问答系统。系统通过上传特定的教材文档，构建知识库，结合大语言模型的能力，为小学生提供准确、专业的Python编程学习辅导。

### 核心特性

- **RAG技术**: 结合知识库检索和大语言模型，提高回答准确性
- **教材上传**: 支持PDF和Word格式教材上传
- **智能分块**: 自动将教材内容分块存储
- **向量检索**: 基于语义相似度的智能检索
- **友好界面**: 基于Streamlit的Web交互界面
- **来源追溯**: 显示回答所参考的教材内容

## 快速开始

### 1. 环境准备

确保已安装Python 3.9或更高版本。

```bash
# 创建虚拟环境（推荐）
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置API Key

1. 复制环境变量模板：
```bash
copy .env.example .env
```

2. 在 `.env` 文件中配置通义千问API Key：
```
DASHSCOPE_API_KEY=your_api_key_here
```

> 获取API Key：访问 [阿里云DashScope控制台](https://dashscope.console.aliyun.com/) 注册并获取

### 4. 运行系统

```bash
# 方式1：使用主程序
python main.py

# 方式2：直接运行Streamlit
streamlit run src/ui/app.py
```

系统将在浏览器中自动打开，默认地址为 `http://localhost:8501`

## 使用说明

### 上传教材

1. 在侧边栏点击"上传教材"
2. 选择PDF或Word格式的教材文件
3. 点击"添加到知识库"按钮
4. 等待系统处理完成

### 开始问答

1. 在输入框中输入Python相关问题
2. 系统会自动检索相关教材内容
3. 基于检索结果生成准确回答
4. 可查看回答参考的教材来源

### 设置选项

- **启用RAG检索**: 开启后会基于上传的教材回答问题
- **显示参考来源**: 显示回答所依据的教材内容
- **清空对话**: 清除当前对话历史
- **清空知识库**: 删除所有已上传的教材数据

## 系统配置

在 `.env` 文件中可配置以下参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| DASHSCOPE_API_KEY | 通义千问API密钥 | - |
| QWEN_MODEL | 使用的模型 | qwen-turbo |
| EMBEDDING_MODEL | 向量嵌入模型 | text-embedding-v2 |
| CHUNK_SIZE | 文本分块大小 | 500 |
| CHUNK_OVERLAP | 分块重叠大小 | 50 |
| TOP_K | 检索返回数量 | 3 |

## 技术栈

- **前端框架**: Streamlit
- **大语言模型**: 阿里云通义千问 (Qwen)
- **向量数据库**: ChromaDB
- **文档处理**: LangChain
- **Embedding**: DashScope Embedding

## 核心原理

### RAG工作流程

1. **文档摄入**: 上传教材文件，系统自动解析和分块
2. **向量化**: 使用Embedding模型将文本转换为向量
3. **存储**: 将向量存储到ChromaDB向量数据库
4. **检索**: 用户提问时，检索最相关的文档块
5. **生成**: 将检索结果作为上下文，结合LLM生成回答

### 为什么选择RAG？

- **准确性**: 基于特定教材回答，减少"幻觉"问题
- **可追溯**: 可以显示回答的知识来源
- **灵活性**: 可随时更新知识库内容
- **成本效益**: 相比微调模型，成本更低

## 常见问题

### Q: API Key配置后仍报错？
A: 确保 `.env` 文件在项目根目录，且API Key正确无误。

### Q: 上传文档后问答没有使用教材内容？
A: 检查是否开启了"启用RAG检索"选项。

### Q: 如何更换大语言模型？
A: 修改 `config/settings.py` 中的模型配置，或修改 `.env` 文件。
