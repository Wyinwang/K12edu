# 小学智能教育问答系统 - 流程图说明文档

## 概述

本文档描述了小学智能教育问答系统的完整运行流程。系统流程已拆分为以下5个独立的流程图，便于理解各个模块的工作方式。

---

## 流程图列表

### 1. 系统启动流程 (`流程图-系统启动.drawio`)

**描述：** 系统从启动到准备接受用户访问的初始化过程。

**流程步骤：**
1. 运行 `main.py` 入口文件
2. 启动 Streamlit Web 服务器
3. 初始化会话状态 (`init_session_state()`)
4. 进入用户认证流程

**关键文件：** `main.py`, `src/ui/app.py`

---

### 2. 用户认证流程 (`流程图-用户认证.drawio`)

**描述：** 用户登录验证流程，包括表单显示、凭据验证和会话状态管理。

**流程步骤：**
1. 检查 `auth_role` 是否为空（判断是否已登录）
2. 若未登录：显示登录表单 (`render_login()`)
3. 用户输入用户名和密码
4. 验证登录 (`verify_login()`)
5. 验证成功：写入会话状态并重启页面
6. 验证失败：显示错误提示，返回登录表单
7. 已登录：直接进入主界面渲染

**关键文件：** `src/auth.py`, `src/ui/app.py`

**会话状态变量：**
- `auth_role`: 用户角色（学生/教师/管理员）
- `auth_username`: 用户名

---

### 3. 文档上传流程 (`流程图-文档上传.drawio`)

**描述：** 教师/管理员上传教学文档到知识库的完整流程。

**适用角色：** 教师、管理员（学生无此权限）

**流程步骤：**
1. 选择目标学科目录（语文/数学/英语等）
2. 上传 PDF 或 DOCX 文件
3. `DocumentProcessor.process_file()` 处理文档
   - 解析文档内容
   - 文本分块（chunking）
4. 调用 Embedding API 生成向量嵌入
5. `VectorStore.add_documents()` 存入向量数据库（Chroma）
6. 文档添加成功，可用于 RAG 问答

**关键文件：**
- `src/rag_engine/document_processor.py`
- `src/rag_engine/vector_store.py`

**技术要点：**
- 支持 PDF、DOCX 格式
- 文本分块提高检索精度
- 向量嵌入使用 Embedding API
- 向量数据库使用 Chroma

---

### 4. 学科问答流程 (`流程图-学科问答.drawio`)

**描述：** 用户进行学科问答的完整流程，支持 RAG（检索增强生成）模式。

**流程步骤：**
1. 选择学科（语文/数学/英语等）
2. 输入问题
3. 判断是否启用 RAG
   - **启用 RAG：**
     - `VectorStore.similarity_search()` 向量相似度检索
     - 构建上下文（拼接参考文档内容）
     - 调用 LLM 生成回答
   - **不启用 RAG：**
     - 直接调用 LLM 生成回答
4. 显示回答（含参考来源，如有）
5. 保存对话历史到 `chat_history`

**关键文件：**
- `src/rag_engine/engine.py`
- `src/llm/unified_llm.py`
- `src/ui/app.py`

**RAG 优势：**
- 回答基于实际教学文档，更准确
- 提供参考来源，可溯源验证
- 适合小学教学内容的专业问答

---

### 5. 练习题生成流程 (`流程图-练习题生成.drawio`)

**描述：** 系统生成练习题、用户作答、自动批改的完整流程。

**支持的题型：**
- 选择题
- 填空题
- 判断题
- 计算题

**流程步骤：**
1. 选择学科
2. 选择题型和题目数量
3. 点击【生成练习题】
4. 判断是否有知识库文档
   - **有文档：** 检索知识库获取相关教学内容
   - **无文档：** 直接生成
5. `ExerciseGenerator.generate_exercises()` 调用 LLM 生成练习题
6. 显示练习题供用户作答
7. 用户填写答案
8. 点击【提交答案】
9. 自动批改，显示分数和解析

**关键文件：**
- `src/exercise_generator.py`（待确认）
- `src/ui/app.py`

**批改机制：**
- 选择题：精确匹配答案
- 填空题：关键词匹配
- 判断题：真假判断
- 计算题：数值答案验证

---

## 技术架构关键词

- **前端：** Streamlit (Python Web 框架)
- **认证：** 会话状态管理 (session_state)
- **文档处理：** PDF/DOCX 解析、文本分块
- **向量数据库：** Chroma
- **向量嵌入：** Embedding API
- **LLM：** 通义千问 (Qwen)
- **RAG：** 检索增强生成 (Retrieval-Augmented Generation)

---

## 如何使用流程图

1. 使用 draw.io 或 diagrams.net 打开 `.drawio` 文件
2. 各流程图独立展示，便于单独查看和讲解
3. 流程图使用标准流程图符号：
   - 圆角矩形：开始/结束
   - 矩形：处理步骤
   - 菱形：判断/分支
   - 虚线框：可选路径或注释
4. 不同颜色标识不同类型的步骤：
   - 绿色：成功/完成
   - 蓝色：用户交互
   - 黄色：LLM/AI 调用
   - 红色：错误/结束
