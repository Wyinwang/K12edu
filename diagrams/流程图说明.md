# 小学智能教育问答系统 - 流程图说明

## 流程图列表

### 1. 系统启动流程 (`流程图-系统启动.drawio`)
从运行 `main.py` 开始，依次启动 Streamlit Web 服务器、初始化会话状态，然后进入用户认证流程，完成系统启动准备工作。

### 2. 用户认证流程 (`流程图-用户认证.drawio`)
检查用户是否已登录（auth_role 是否为空），未登录则显示登录表单，验证用户名密码后写入会话状态并重启页面；已登录则直接进入主界面渲染。

### 3. 文档上传流程 (`流程图-文档上传.drawio`)
教师或管理员选择学科目录后上传 PDF/DOCX 文件，系统通过 DocumentProcessor 解析并分块文档，生成向量嵌入后存入 Chroma 向量数据库，完成知识库文档添加。

### 4. 学科问答流程 (`流程图-学科问答.drawio`)
用户选择学科并输入问题，若启用 RAG 则先从向量数据库检索相关文档构建上下文，再调用 LLM 生成回答；未启用则直接调用 LLM，最后保存对话历史。

### 5. 练习题生成流程 (`流程图-练习题生成.drawio`)
用户选择学科、题型（选择/填空/判断/计算）和数量后点击生成，系统根据知识库内容（如有）调用 LLM 生成练习题，用户作答提交后自动批改并显示分数与解析。
