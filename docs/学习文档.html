1项目概述

1.1 项目背景

本项目是一个基于检索增强生成（RAG）技术的Python小学智能教育问答系统。系统通过上传教材文档构建知识库，结合大语言模型的能力，为小学生提供准确、专业的学习辅导。

1.2 项目目标

  • 实现多学科（语文、数学、英语）智能问答
  • 基于上传教材提供准确的知识解答
  • 自动生成练习题并支持答题评估
  • 跟踪学习进度，分析薄弱知识点
  • 支持多角色用户管理（学生、教师、管理员）

1.3 核心特性

特性 说明
RAG技术 结合知识库检索和大语言模型，提高回答准确性
教材上传 支持PDF和Word格式教材上传
智能分块 自动将教材内容分块存储
向量检索 基于语义相似度的智能检索
练习题生成 AI自动生成选择题、填空题、判断题等
学习跟踪 记录学习进度，生成错题本
多LLM支持 支持通义千问、DeepSeek、Ollama等多个模型

2核心技术原理

2.1 RAG（检索增强生成）技术

RAG是什么？
RAG = Retrieval-Augmented Generation（检索增强生成），是一种将信息检索与大语言模型生成相结合的技术。

为什么需要RAG？

大语言模型虽然知识丰富，但存在以下问题：

  • 幻觉问题：可能生成不准确或虚构的内容
  • 知识时效性：无法获取最新的知识
  • 专业性不足：对特定领域知识不够深入

RAG通过先检索相关知识，再基于检索结果生成回答，解决了上述问题。

RAG工作流程

1. 文档摄入 → 上传教材，系统解析和分块
2. 向量化   → 使用Embedding模型将文本转为向量
3. 存储     → 将向量存入向量数据库(ChromaDB)
4. 检索     → 用户提问时，检索最相关的文档块
5. 生成     → 将检索结果作为上下文，结合LLM生成回答

2.2 向量存储与Embedding

什么是文本向量（Embedding）？

文本向量是将文本转换为数值向量的过程。例如：

"语文学习很重要" → [0.23, -0.15, 0.89, 0.42, ...]
这些数值代表了文本的语义特征，相似的文本会有相似的向量。

向量检索原理

向量检索通过计算相似度来找到最相关的文档：

  • 余弦相似度：计算两个向量夹角的余弦值
  • 欧氏距离：计算两个向量之间的距离

相似度越高，文本越相关。

本项目使用的Embedding模型

  • 通义千问：text-embedding-v3（阿里云）
  • OpenAI：text-embedding-3-small
  • Gemini：models/embedding-001

2.3 大语言模型（LLM）

什么是LLM？

大语言模型是基于Transformer架构的深度学习模型，能够理解和生成人类语言。

本项目支持的LLM

提供商 模型 特点
阿里云通义千问 qwen3.5-plus 中文能力强，适合教育场景
DeepSeek deepseek-chat 性价比高
字节跳动豆包 doubao-pro-32k 长文本支持
Ollama本地 qwen2.5:14b 本地部署，无需网络

6关键代码解析

6.1 RAG查询核心代码

# src/rag_engine/engine.py - query方法核心逻辑

def query(self, question: str, use_rag: bool = True, show_sources: bool = True):
    """查询问题的核心方法"""
    context = None
    sources = []

    if use_rag:
        # 1. 检索相关文档
        results = self.vector_store.similarity_search_with_score(question, k=self.top_k)

        if results:
            # 2. 构建上下文
            context_parts = []
            for doc, score in results:
                context_parts.append(doc.page_content)  # 文档内容
                sources.append({
                    "content": doc.page_content[:200],
                    "source": doc.metadata.get("source"),
                    "score": round(1 - score, 4)  # 相似度分数
                })
            context = "\n\n---\n\n".join(context_parts)

    # 3. 调用LLM生成回答
    answer = self.llm.chat(question, context)

    return {
        "answer": answer,
        "sources": sources,
        "used_rag": use_rag and context is not None
    }
关键点：query方法先检索相关知识，再将检索结果作为上下文传给LLM，实现RAG流程。

6.3 文档分块处理

# src/document_processor/processor.py

class DocumentProcessor:
    def __init__(self, chunk_size=500, chunk_overlap=50):
        """初始化文档处理器"""
        self.text_splitter = RecursiveCharacterTextSplitter(
            chunk_size=chunk_size,
            chunk_overlap=chunk_overlap,
            separators=["\n\n", "\n", "。", "！", "？", "；", "，", " ", ""]
        )

    def split_documents(self, documents):
        """将文档分割成文本块"""
        return self.text_splitter.split_documents(documents)
分块策略：使用RecursiveCharacterTextSplitter，优先按段落(\n\n)分割，再按句子分割，保证语义完整性。重叠50字符确保上下文连贯。
